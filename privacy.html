Privacy policy

Lombaad Publisher · Effective 25 October 2026

Lombaad Publisher ("the tool") is a personal program run by the owner of the Lombaad channel on their own computer. This page explains what data it uses and what happens to it.

Who the tool works for

The tool only acts on the YouTube channel and Instagram account that the owner signs in to. It does not collect data about viewers, other users or anyone else's accounts.

Data the tool accesses

From YouTube (YouTube API Services), with the owner's permission:

  • Basic channel details: channel name and subscriber count.
  • The ability to upload videos, set titles, descriptions and thumbnails, and schedule releases on the owner's channel.
  • Statistics for the owner's own videos: views, watch time, audience retention, subscribers gained, traffic sources, search terms that led to the videos and, if the channel is monetised, revenue figures.

All YouTube statistics are totals per video, as YouTube provides them. They do not identify individual viewers.

From Instagram (Meta Graph API), with the owner's permission:

  • The ability to publish Reels to the owner's Instagram account.
  • Statistics for those Reels: views, reach, likes, comments, shares and saves, as totals per post.

How the data is used

  • To publish the owner's videos at the scheduled time.
  • To show the owner how each video is performing.
  • To write a weekly report about which topics and titles work best. To write that report, the per-video statistics (no personal information) are sent to Anthropic's Claude API for analysis. Anthropic's handling of that data is covered by the Anthropic Privacy Policy.

The data is never sold, never used for advertising and never shared with anyone else.

Where the data is stored

Everything is stored only on the owner's own computer: the sign-in tokens, a local database of videos and their statistics, and the weekly reports. Nothing is stored on a server run by this tool.

How long it is kept, and deleting it

Data is kept until the owner deletes it. The owner can delete everything at any time:

  • python -m hindi_content forget youtube deletes all stored YouTube data, including statistics, reports and the sign-in token.
  • python -m hindi_content forget instagram deletes all stored Instagram data.

Revoking access

  • YouTube / Google: remove the app at the Google security settings page.
  • Instagram / Meta: remove the app under Settings → Apps and websites in Instagram, or delete the system-user token in Meta Business Suite.

Google and YouTube

The tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of your data is covered by the Google Privacy Policy.

Changes

If this policy changes, the new version will be posted on this page with a new effective date.
